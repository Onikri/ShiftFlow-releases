# ShiftFlow releases

Android APK releases and update metadata for ShiftFlow.

Download the APK from the latest release. In ShiftFlow settings, use `Onikri/ShiftFlow-releases` as the update source. Updates are checked daily; Android asks for confirmation before installation.

Each release includes `ShiftFlow.apk`, `shiftflow-update.json` and `SHA256SUMS`. Verify the SHA-256 checksum before manual installation. Install updates over the existing application to retain its data.

This repository contains no application source code, invoices, photographs or user databases.
